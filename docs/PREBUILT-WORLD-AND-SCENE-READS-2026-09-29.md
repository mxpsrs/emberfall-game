# Prebuilt world construction and Scene reads — 29 September 2026

The shared-world exporter now writes a deterministic construction graph before generating its server navigation catalog. The browser and editor hydrate that graph instead of rebuilding settlements, rooms, roads, ecology and quest scenery. Reference encoding preserves Maps, Sets, cyclic building/service links and lexical gameplay references. The artifact contains no player save. It is generated by `npm run build`, ignored as build output, versioned by the asset manifest, Brotli-compressed and included in the published Worker.

Current-layout saves and fresh default characters use the fast path. Older layout saves retain the existing procedural migration sequence. Network failure falls back before any hydration. Character inventory, bank, XP, quest progress and door state stay character-owned. The existing editor layer and native ownership migration still run after hydration, preserving canonical authored edits and native Scene authority.

The native bridge provides a synchronous read scope for drawing: repeated entity/revision reads share one revision check. Scene writes refresh the scope before observers or subsequent getters run, including batched writes and editor commands. Projection poses are reused by immutable native record identity; nested component views are reused by path and container type.

Local production-world Filament NOOP measurements: construction 35.66 s → 0.95 s; native import 25.98 s → 26.35 s; first draw 14.52 s → 15.11 s. Their startup subtotal was 76.16 s → 42.41 s. Median subsequent CPU draws were 131.28 ms → 121.27 ms. These are separate local runs, not physical-device FPS or network loading measurements. Native import and frame cost remain substantial.

Verification covers graph/reference parity, tutorial entry, saved progress and position, legacy/network fallback, invalid graph rejection, in-batch transform/component updates, native simulation, and the full building/door/spawn/resource Scene ownership roundtrip. See the companion QA JSON. `tests/prebuilt-world.cjs` requires a generated construction asset (run the build first).

The API bundle only changes whitespace/syntax minification to accommodate the additional static asset under the hosting module limit. Exported identifiers remain intact. No server protocol, database schema, account reset or maintenance disconnection is part of this compatible client update.
