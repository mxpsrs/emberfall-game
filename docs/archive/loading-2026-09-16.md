# Loading pause reduction — 16 September 2026

The owner reported high loading times after Work Run 2. Profiling separated terrain work from avatar preparation: the major wide-view pause came from first-use armour fitting. Each sleeve row rescanned and allocated the same full-body triangle intersections for twelve directions. The character could be an NPC or player; GPU skinning also requests the same fitted material.

`contouredLimbPlates` now computes each exact cross-section once, rejects triangles outside that plane before allocating, and reuses the ordered intersections for every ray. Its temporary plane cache is released when fitting completes; the existing six completed contour caches remain bounded. No assets, vertices, scenery, terrain, character shape, lighting, drawing distance, animation or gameplay rules are removed or changed.

Six approved male/female upper-arm, forearm and thigh meshes remain byte-identical, including normals, colours, indices and skin weights. The dedicated regression compares all these arrays with their pre-change hashes and verifies completed-mesh reuse.

## Measurements

See `qa/loading-2026-09-16.json`. Individual contour fitting fell from approximately 3.7–7.9 seconds to 44–64 milliseconds. In the existing CPU/submission probe, first wide tutorial draw fell from 19.18 to 3.33 seconds, and first wide mainland draw from 24.27 to 10.13 seconds. Draw calls and submitted vertex counts are identical in every sampled view. Near tutorial draw varied from 1.43 to 1.65 seconds; the change targets previously unseen armour, not all startup work. The phone-sized view in this probe follows the desktop view and reuses its caches; it is not an independent cold-phone result.

These numbers measure local first-render CPU preparation, not total network/page load, actual GPU execution or physical-device FPS. Download and world-initialization costs remain, and widest mainland preparation can still take around ten seconds. The prior Work Run 2 report's 26-second figure describes the earlier build.

## Verification and release

Passed: exact-contour parity, all five armour tiers on both bodies, equipment fitting and all slots, modular equipment, NPC appearance, texture skinning, and built production assets. This is a focused performance patch; the previous complete-suite record remains in Work Run 2.

Only client rendering code and test/report files change. Server modules, shared catalog, protocol and player data are unchanged, so this compatible publication keeps the game open under AGENTS.md.
