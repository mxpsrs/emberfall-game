# Veldren Work Run 2 — completion record

Phase 2 continues the tested combat, Spirit, multiplayer and interface foundation. Existing skill names and save/item IDs remain compatible. No account reset, schema change or Run 3 expansion is included.

## Progression, magic and equipment

The completed Phase 2 implementation retains all fourteen requested skills and adds independently saved Relic Shaping. Successful gathering milestones at 12, 48 and 120 actions connect Firemaking/Fire, Fishing/Water, Woodcutting/Air and Mining/Earth. Attack, Strength and Defence retain the tested combat styles and Spirit build interactions. Ten lodestone seams across five quarries, eight level-gated patterns and the existing school-altar quest connect gathering, inscription and usable Relics.

Combat, Support, Relics and Travel pages explain progression. Trailwind, Mending Current and Bondlight add energy, healing and Spirit support. Home Teleport remains purple, free of Relic and XP changes, and requires five seconds outside combat before returning to Briarhaven; server authorization and observer animation tests pass.

Charsteel, Windsteel, Deepiron, Eldrite and Wyrmforged preserve compatible internal IDs. Three-piece equipment traits, weight, guard, ward and attunement support different builds. Existing equipment fitting, always-worn tool belt and bow-related quiver behavior pass regression coverage.

## Opening and interfaces

Firstlight Isle introduces four connected chapters and the First Accord while retaining Rowan, Captain Vale, the Mysterious Man and all 38 lessons. Explicit banking follows deposit, withdrawal, 1 / 5 / 10 / All controls and the Worship handoff. Cooking recovery and non-modal interfaces from the prior repair remain intact: conversations, banking and equipment do not stop world simulation or camera controls.

A fresh character completed all 38 lessons in the actual browser client at 844 × 390, including Bram, banking prompts, first Spirit and mainland departure. A separate real-client/local-server walkthrough passed with 1,184 polls and 52 action receipts. This is local server evidence, not an authenticated hosted tutorial certification.

## Entire-world environment work

The shared deterministic placement pass covers every generated scene. Final audit: **339 scenes, zero recorded placement/foundation violations**, 4,157 mainland trees, 38 Firstlight trees and nine Fairy Lands trees. This refinement removes 45 unsafe mainland placements from the previous 4,202-tree layout while preserving forest clusters and cleared settlements. Cave outcrops, castle walls, full bridge spans and approaches now reserve appropriate tree clearance. Generic open-country location labels are **Badlands**; named forests and settlements retain their identities.

Fixed double terrain grading that tilted 20 building foundations, including Briarhaven. Lake-bank distance is continuous instead of producing rectangular cliffs. Quarry ramps retain a level loading apron and a gradual outer transition without neighboring foundation blends filling excavations. Mountains and wilderness retain elevation. Ashwatch's entrance moves clear of Crownreach's wall, and an Ironhollow traveler moves from an isolated rock pocket onto accessible ground. Generated placement cache and shared server catalog were rebuilt together.

Whole-mainland path searches verify an accessible adjacent interaction tile for resources, NPCs, tutors, passage entrances and quest objects, every house entrance, all settlements and bridges. Prop, cave, road, terrain and indoor-placement tests also pass. This establishes navigable interaction approaches; it does not claim every possible free-roaming path is optimal.

## Actual visual inspection

Reviewed **119 locations** with the production renderer and representative opposite camera angles, then fixed and rechecked discovered defects:

- All 13 settlements: Briarhaven, Crownreach, Greyhaven, Willowcross, Stoneford, Ironhollow, Deepforge, Copperdelve, Stonehearth, Aelindor, Moonwillow, Fernwatch and Silverbrook.
- Firstlight's opening, timber grove, fishing shore, Bram's kitchen, magic school, mine and dungeon; Fairy Lands lake.
- All five surface quarries, all seven bridges, 14 major cave/underground entrances and the four existing boss approaches.
- Elderwood, Crownwood, Westmere Woods, Ironpine Foothills, Stonehearth Pines and Silverwood Forest; Reedwater Mere, Fenmere, Ironmirror and Silverglass lake banks.
- Major roads between kingdoms and settlements, goblin routes, northern/eastern Badlands, existing main-story and mountain-quest approaches, and all 20 originally uneven foundations.

Review fixtures use real rendering with controlled positioning and requested frames. They are reproducible development tools and are removed before the release build. Selected screenshots are in `qa/work-run-2/`.

Visual review exposed a software/picking renderer crash on packed quarry geometry; the mesh transformation now supports the packed format, with a dedicated regression. Lake cliffs, cave/wall overlap, tree clearances and quarry transitions were corrected after visual review. Clean tutorial browser logs had no application errors; earlier preview reload failures were resolved by a clean reload.

## Validation and performance limits

See `qa/work-run-2/tests.json` for all 145 available test programs, including targeted rechecks of repaired failures. The aggregate runner was interrupted by a tool-session disconnect after 137 results; remaining programs and affected tests were run separately. Stale assertions were corrected for non-modal interfaces, the new saved skill, named Magic tabs and the existing unfinished Relic quest. Gameplay tests were not disabled.

Coverage includes combat, all Spirit actions, discovery, Relics, equipment, tutorial, camera, mobile-sensitive long press/right click, doors, trade, following, drops, quests, multiplayer visibility, day/night, account/save recovery and local-file storage. Production assets are rebuilt and checked separately. No live account data is reset during this release.

CPU/submission probes measured warm tutorial medians of about 6–11 ms and wide mainland 20.7 ms, with 111–301 draw calls in sampled views. Mainland tree count is slightly lower; warm measurements remain within the prior Phase 2 range. Cold geometry preparation at the widest view still reaches **25.8 seconds**. This is a known startup limitation, not a measured new regression. GPU/device frame rates and physical-phone performance are not certified by these probes. Software browser rendering is used for inspection, not FPS claims. Local 39-client tests pass; sustained authenticated hosted capacity for 39 players remains unverified.

Exact commit and deployment results are reported in the release response after verification.
